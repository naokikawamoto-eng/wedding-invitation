# Wedding Quiz — 一次会・二次会リアルタイムクイズ

ゲストは自分のスマホで回答し、主催者は手元の画面で進行します。
会場のスクリーンには問題・QR・順位だけが大きく出ます。正解は、主催者が「正解を発表する」を押すまでゲストにもスクリーンにも渡りません。

一次会（披露宴）と二次会は **別ルーム** です。参加者・得点・問題は混ざりません。

| 回 | ルームコード | ゲスト | 主催者 | 会場スクリーン |
|---|---|---|---|---|
| 一次会（披露宴） | `1122A` | `/play/1122A` | `/admin/1122A` | `/screen/1122A` |
| 二次会 | `1122B` | `/play/1122B` | `/admin/1122B` | `/screen/1122B` |

トップページからも、どちらの回かに入れます。

進行は次のボタンです。

```
[Q1 を表示する] → [回答を締め切る] → [正解を発表する] → [Q2 を表示する] → … → [最終結果を発表する]
```

制限時間（初期値は一次会 45 秒・二次会 30 秒）を過ぎると、サーバーが回答を締め切ります。「無制限」にすると、締め切りボタンを押すまで受け付けます。

---

## いま入っている問題

`1122A`（一次会）は、招待状に書いてある事実だけのサンプル5問です。本番は新郎新婦についての問題に差し替える予定です。
`1122B`（二次会）は披露宴の振り返り10問です。Q8だけ「未定」で、プロフィールムービーの問題が決まり次第差し替えてください。

記述式の別解は、正解欄に 1 行ずつ足します（「河本直樹」「河本 直樹」のように）。

## 画面

| URL | 使う人 | 内容 |
|---|---|---|
| `/` | ゲスト | 一次会・二次会への入口。コード手入力もできる |
| `/play/{コード}` | ゲスト | ニックネーム → 待機 → 回答 → 正解/不正解 → 最終順位 |
| `/admin` | 主催者 | 合言葉。当日ルームと、リハーサル用ルームの作成 |
| `/admin/{コード}` | 主催者 | 進行 / 問題 / ランキング / 分析 |
| `/screen/{コード}` | 会場スクリーン | 合言葉不要。待機中は QR、出題中は問題、最後は順位 |

スクリーンはプロジェクターで全画面（F11）にします。進行は別のタブレットで `/admin/{コード}` を開いてください。

---

## 保存のしかた

状態は **1 つの JSON** にまとめてあります。約 100 人が同時に回答しても、書き込みは直列化して取りこぼしません。

- **本番（Vercel）**: 非公開の [Vercel Blob](https://vercel.com/docs/vercel-blob)。東京リージョン（`hnd1`）。正解データは公開 URL に置きません
- **手元**: `quiz-app/data/quiz-state.json`（git には入りません）

Firebase は使っていません。招待状サイトとは別の Vercel プロジェクトで、Root Directory を `quiz-app` にしてデプロイします。

ゲストの画面は約 0.8 秒おきに最新状態を取りにいきます。会場の Wi-Fi が不安定でも、切れたタブを開き直せば続きから参加できます（同じブラウザならニックネームも残ります）。

## ローカルで動かす

Node.js 22 以上。

```bash
cd quiz-app
npm install
npm run dev
```

- ゲスト: http://localhost:3000
- 主催者: http://localhost:3000/admin
- 合言葉: `wedding2026`（変えるときは `QUIZ_HOST_PASSCODE`）
- スクリーン: http://localhost:3000/screen/1122A

別ブラウザやシークレットウィンドウを開くと、別のゲストとして参加できます。

```bash
npm test
npm run typecheck
```

## 本番（Vercel）

招待状とは **別プロジェクト** にし、Root Directory を `quiz-app` にします。

1. Vercel でプロジェクトを作る（Framework: Next.js、Root Directory: `quiz-app`）
2. Storage で **Private** の Blob ストアを作り、このプロジェクトに接続する（`BLOB_STORE_ID` が付く）
3. 環境変数 `QUIZ_HOST_PASSCODE` を、ソースコードに書かない合言葉で設定する。未設定だと主催者画面に入れません
4. デプロイ後、`/admin` で合言葉を通し、`/play/1122A` と `/screen/1122A` が開くことを確認する

関数リージョンは `vercel.json` で東京（`hnd1`）に固定しています。
